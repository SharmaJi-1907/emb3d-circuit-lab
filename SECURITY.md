# Security policy

## Reporting a problem

If you find a security problem in CircuitLab (for example, a way to read someone else's projects, run code in another user's browser, or reach the admin panel), **please don't open a public issue**. Instead, report it privately through GitHub: **Security → Report a vulnerability** on this repository.

Please include what you found, the steps to reproduce it, and what an attacker could do with it. You'll get a reply as soon as possible, and credit in the changelog if you want it.

## Supported versions

Only the latest version on `main` (the live site) is supported. There are no older releases to patch.

## How the project stays safe

The rules the code follows are in [docs/rules/SECURITY_RULES.md](docs/rules/SECURITY_RULES.md).
